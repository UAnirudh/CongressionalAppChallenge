## Scope and implemented behavior

The MVP uses Next.js App Router, TypeScript, Tailwind CSS, a local editable shadcn/ui-style Button, Recharts, Zod, Vitest, Playwright, and Sharp for image validation. Exactly two problem types are supported:

1. `projectile_motion`: SI speed 0–100 m/s, angle 0–90 degrees, positive gravity 0.1–30 m/s². Launch and landing at equal height, constant gravity, no drag. Review/edit model and assumptions; real-time SVG, speed/angle sliders, flight time, range, peak height. Equal plotting scales preserve physical angle. Slider values retain fractional extracted parameters.
2. `linear_function`: unitless y=mx+b, slope −100–100, intercept −1000–1000; editable numeric drafts, real-time Recharts graph over x from −10 to 10.

The landing page has typed input, a PNG/JPEG/WebP upload, explicit image consent, and two clearly labeled sample exercises. `/api/interpret` bounds request bytes/text, fully decodes still images up to 2 MB and 16 megapixels, calls OpenAI server-side with `store: false`, parses JSON, and validates the result with strict Zod schemas. It honestly reports unsupported problems, missing credentials, provider failures, invalid output, and input errors. It never executes model-generated code or pretends a sample is an AI result. Review is required before simulation. Prediction mode hides results until deterministic checking; variable changes reset the answer. Failed interpretation preserves the current model, pausing competing controls while pending.

All calculations are in `src/lib/math.ts` and independent of React. Model contracts and units are in `src/lib/models.ts`. Shared public upload limits are in `src/lib/upload.ts`; the provider adapter is server-imported in `src/lib/interpretation.ts`. No accounts, database, analytics, or permanent upload storage exist.
