# IBM Plex font assets

Unmodified Latin WOFF2 font files from Google Fonts. The sans file is variable; mono uses regular and medium. The matching SIL Open Font Licenses are included alongside the files.

These files are bundled through next/font/local. Builds and page views do not fetch font assets from Google.
